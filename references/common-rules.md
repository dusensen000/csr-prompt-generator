# 通用规则库

本文件包含所有提示词共享的通用规则，在生成提示词时注入到对应位置。

---

## 一、执行步骤通用规则

### 第一步：检索 TFL 表格

注意：
- 使用requirement参数进行搜索，不要使用fileNameHint
- 搜索关键词应基于本章节的数据需求描述，而非具体表名
- 如果搜索结果不匹配，可以调整requirement关键词重新搜索
- 如果检索不到匹配的表格，对应的正文段落应被删除

### 第二步：分析表格结构，识别数据字段

仔细分析读取到的表格 Markdown 内容，识别以下信息：
1. 表格的列定义（各分组名称、合计列）
2. 表格的行定义（各项统计指标）
3. 表格脚注中的特殊说明
4. 表格中的层级关系（如药物→分组、SOC→PT等）

重要原则：
- 不要预设具体的药物名称或分组名称，根据表格列定义自动识别
- 不要预设具体的字段名称，根据表格行定义自动识别
- 如果表格中有层级关系（如药物→分组），要识别这种层级
- 脚注中可能包含重要的补充说明，需要提取

---

## 二、动态段落生成规则

- 根据实际检索到的表格数量和内容动态生成段落
- 如果某个表格检索不到，对应段落应被删除
- 不要编造不存在的数据
- 根据表格实际包含的字段动态生成描述（不预设字段名称）

---

## 三、数据校验规则

1. 若总例数与各组例数之和不一致，优先保留表中原始值，并标记为数据不一致。
2. 若百分比与例数不匹配，优先保留表中原始百分比，不自行重算。
3. 直接使用表格中的原数据，不要自行修改小数位数或进行四舍五入。
4. 若完成试验例数与提前退出试验例数之和不等于随机入组总例数，标记为数据不一致。
5. 若各退出原因例数之和不等于提前退出总例数，标记为数据不一致。

---

## 四、异常处理规则

1. 若表格读取失败，明确返回失败原因及对应表格唯一码。
2. 若某段生成所需关键字段缺失，则跳过该段的生成，并说明缺失字段。
3. 若某项例数为0或该字段不存在，则不写对应描述，不得编造。
4. 如果检索不到匹配的表格，对应的正文段落应被删除，不要编造数据。
5. 【重要】正文中绝对不能出现以下类型的句子：
   - "现有检索结果未提供..."
   - "未检索到..."
   - "无法从现有结果中..."
   - "缺少...数据"
   - "没有...信息"
   - 任何说明"数据缺失"或"检索失败"的句子
   如果某个数据在表格中不存在，直接跳过该段落，不要在正文中说明原因。

---

## 五、统一写作规则

1. 使用正式、客观、专业的 CSR 中文写作风格。
2. 不得臆造表中不存在的数据、原因、归因或结论。
3. 术语应保持一致，使用表格中实际的分组名称（如"试验组""对照组"或其他实际分组名称）。
4. 各段内容仅能使用指定表格中的数据，不得跨表混用或自行补充。
5. 统一使用"例"作为受试者计数单位，不要使用"人次""名"等其他单位。
6. 直接使用表格中的原数据，不要自行修改小数位数或进行四舍五入。
7. 不要输出表格下方的注释内容作为独立段落，但可以将注释中的关键信息融入正文描述中。
8. 不要添加表格中没有的解释性文字。
9. 如果表格数据不足以支撑某段的完整描述，只描述有数据支持的部分，不要编造补充。
10. 描述剂量调整时，使用"发生率""发生情况"等表述，不要过度解读因果关系。
11. 对于"略高于""略低于"的描述，要基于实际数据差异大小来判断。
12. 根据表格实际包含的字段动态生成描述，不要预设固定的字段名称。
13. 【重要】正文中只能包含基于表格数据生成的描述性内容，不能包含任何说明"数据缺失"、"检索失败"、"无法生成"等元信息的句子。如果某个段落无法生成，直接删除该段落，不要在正文中说明原因。

---

## 六、图/表占位符及引用规则

**适用条件**：此规则仅在例文包含实际表格数据时适用。如果例文只包含表格引用信息（如"详见表X"）而不包含实际表格数据，则不需要此规则。

1. 正文中引用表格时使用 $TABLE{表_xxx} 占位符格式
2. 正文中引用图片时使用 $IMAGE{图_xxx} 占位符格式
3. 每个表格/图片上方要输出标题：
   - 表格标题格式：表* xxx（xxx为表格文件名中的名称，不要包含编号）
   - 图片标题格式：图* xxx（xxx为图片文件名中的名称，不要包含编号）
4. 表格/图片标题和占位符要换行写
5. 程序会自动将 $TABLE{表_xxx} 替换为正确的表格编号（如表14.2.1.1）
6. 只要生成了占位符，正文中就必须有对应的交叉引用
7. 【强制检查】正文引用与占位符对应规则：
   - 在生成正文时，每使用一个 $TABLE{表_xxx} 交叉引用，就必须在文末生成对应的占位符
   - 反之，每生成一个占位符，正文中就必须有对应的 $TABLE{表_xxx} 交叉引用
   - 如果正文中没有某表格的交叉引用，就不能生成该表格的占位符
   - 检查方法：生成正文后，统计 $TABLE{表_xxx} 的数量，与文末占位符数量对比，必须相等

**不适用条件**：如果例文只包含表格引用信息（如"详见表14.3.6.1"）和附件引用信息（如"详见附件列表16.2.9.1"），则：
- 不需要生成占位符
- 不需要交叉引用规则
- 直接输出表格编号和附件编号即可

## 七、输出格式规则

### 最终输出格式
1. 仅输出对应章节正文
2. 如正文确需插入原始表格，仅在正文相应位置输出占位符

### 最终输出补充要求
1. 最终结果必须是一个完整 Markdown 文本。
2. 若需要插入原始表格，必须输出工具返回的 placeholder，不得改写占位符文本。
3. 程序会在最后一步执行完成后，将 Markdown 转为 HTML，并用 placeholder 替换为实际 HTML 表格内容。
4. 不要输出类似"TFL 数据集引用""原始表格 HTML 路径""原始表格"之类的标题。

---

## 八、表格绑定内容通用化规则

在生成提示词时，对于从例文中识别的表格绑定内容，必须进行通用化处理：

### 通用化原则
1. 将具体药物名称替换为 [药物A]、[药物B] 等占位符
2. 将具体数值替换为 [数值] 占位符
3. 将具体分组名称替换为 [试验组]、[对照组] 等占位符
4. 保留固定的描述格式和句式结构
5. 确保模板能应对不同数量的药物/分组

### 示例

**原始例文内容（具体数据）：**
```
金妥昔单抗的平均暴露持续时间为22.21周（SD：22.379）
```

**通用化后的提示词内容：**
```
[药物A]的平均暴露持续时间为[数值]周（SD：[数值]）
```

### 常用通用格式模板

#### 例数+百分比格式
```
共[数值]例（[百分比]%）受试者发生[事件类型]，其中[分组1][数值]例（[百分比]%），[分组2][数值]例（[百分比]%）
```

#### 统计量格式
```
[指标名称]：均值（标准差）=[数值]（[数值]），中位数（Q1，Q3）=[数值]（[数值]，[数值]），范围=[数值]~[数值]
```

#### 比较格式
```
[药物A]的[指标]为[数值][单位]，略高于/低于/相似于[药物B]的[数值][单位]
```

#### 发生率比较格式
```
[分组1]中有[百分比]%的受试者发生[事件]，高于/低于[分组2]的[百分比]%
```

## 九、段落功能描述规则

在提示词中描述每个段落时，应包含以下要素：

1. **描述内容**：这段要描述什么（主题/目的）
2. **写作格式**：具体的句式结构（使用通用占位符）
3. **表格绑定字段**：从表格中提取哪些字段
4. **数据来源**：这些字段在表格中的位置

### 示例格式

```
第一段：药物暴露持续时间（如果检索到药物暴露表格）
描述内容：描述各药物/分组的暴露持续时间比较
写作格式：
- 开头：基于SS
- 描述[药物A]的暴露持续时间（均值、标准差、中位数、Q1/Q3）
- 描述[药物B]的暴露持续时间
- 在描述数据时，加入组间的比较和说明（如"略高于""略低于""总体相似"等）
表格绑定字段：
- 暴露持续时间：从表格Mean(SD)、Median(Q1,Q3)行提取
- 药物名称：从表格行定义中提取
- 分组名称：从表格列定义中提取
```

## 十、固定字段与变量字段分离规则

在生成提示词时，应明确区分固定字段和变量字段，以便于后续维护和适配不同研究项目。

### 定义

- **固定字段**：由模板确定、每次输出都应保留的标题、标签、表头、固定句式、固定说明、固定表格结构。这些内容在不同研究项目中保持不变。
- **变量字段**：来自当前项目输入的名称、日期、数值、单位、标准、结论、访视、周期、操作步骤、表格单元格内容等。这些内容会根据具体研究项目而变化。

### 处理原则

1. 固定字段应直接写入提示词，作为硬性约束
2. 变量字段应写成输入要求或占位符，不固化为默认内容
3. 例文或样例数据中的变量值只用于判断写法和字段位置，不能直接固化为 skill 默认内容

### 示例

**固定字段**（直接写入提示词）：
```
章节标题：[药物暴露]()
表格标题格式：表* xxx
固定句式：本研究中，[药物名称]的平均暴露持续时间为[数值]周
```

**变量字段**（写成占位符或输入要求）：
```
药物名称：从 TFL 表格行定义中提取
分组名称：从 TFL 表格列定义中提取
暴露持续时间：从表格 Mean(SD) 行提取
百分比：从表格 % 列提取
```

### 与表格绑定内容的关系

表格绑定内容是变量字段的一个子集，专门针对 TFL 数据驱动的内容：
- 表格绑定字段 = 从 TFL 表格中提取的变量字段
- 通用占位符 = 变量字段的表示方式（如 [药物A]、[数值]）
- 固定字段 = 模板锁定的非变量内容

## 十一、简单章节处理规则

对于简单章节（例文非常简短，通常只有一句话），适用以下特殊规则：

### 11.1 例文分析规则

1. **长度判断**：如果例文长度 ≤ 1 句话，可能是简单章节
2. **引用分析**：检查例文是否包含以下引用：
   - 表格引用：如"见表 X.X"、"详见附表"
   - 章节引用：如"见 X.X 章节"、"详见第 X 章"
   - 附件引用：如"详见附件 X.X"
3. **工具确定**：
   - 如果包含表格引用 → 使用 `read_tfl`
   - 如果包含章节引用 → **不使用任何工具**，直接在提示词中写明章节名称
   - 如果没有引用任何内容 → 可能不需要使用工具

### 11.2 章节引用处理规则

**重要**：`read_document` 工具不能处理章节引用情况，如果例文引用了章节，直接在提示词中写明章节名称。

1. **章节名称提取**：从例文中提取章节名称，不要使用章节编号
   - 例文："详见 9.3.1 入选标准" → 章节名称："入选标准"
   - 例文："见 11.4.1 主要疗效终点" → 章节名称："主要疗效终点"

2. **章节链接格式**：使用 `[章节名称]()` 格式生成可点击链接
   - 示例：`详见 [入选标准]() 章节`
   - 转换为 HTML 后，链接可点击跳转到对应章节

3. **章节名称占位符**：在提示词中使用 `{章节名称}` 占位符
   - 生成时替换为实际章节名称
   - 保持格式一致：`[章节名称]()`

### 11.3 提示词生成规则

1. **不要套用复杂模板**：简单章节不使用模板 A-H，使用简化结构
2. **保持简洁**：提示词应简短明了，不要添加不必要的复杂规则
3. **固定输出格式**：根据例文分析确定输出格式
4. **检索策略**：明确说明使用什么工具、检索什么关键词

### 11.4 输出格式规则

1. **情况一：找到相关内容**
   - 输出表格引用或章节引用
   - 保持与例文一致的格式

2. **情况二：未找到相关内容**
   - 输出固定内容（通常是一句话描述）
   - 不要编造不存在的内容

### 11.5 示例

**示例 1：表格引用**
**例文**："个体疗效数据列表见表 11.4.3-01"

**分析**：
- 长度：1 句话 → 简单章节
- 引用：包含表格引用"见表 11.4.3-01"
- 工具：使用 `read_tfl`

**提示词结构**：
```
# 11.4.3 个体疗效数据列表

## 任务描述
根据检索结果撰写本章节正文。

## 检索策略
1. 使用 read_tfl 检索"个体疗效数据列表"相关表格
2. 如果找到相关表格，输出参考信息
3. 如果未找到相关表格，输出固定内容

## 输出格式
### 情况一：找到相关表格
个体疗效数据列表见表 11.4.3-01。

### 情况二：未找到相关表格
个体疗效数据列表见相应的统计分析表格。

## 输出要求
- 保持专业、客观的语气
- 遵循 CSR 正文风格
```

**示例 2：章节引用**
**例文**："详见 9.3.1 入选标准"

**分析**：
- 长度：1 句话 → 简单章节
- 引用：包含章节引用"见 9.3.1 入选标准"
- 工具：不使用任何工具，直接写明章节名称

**提示词结构**：
```
# 9.3.1 入选标准

## 任务描述
根据检索结果撰写本章节正文。

## 章节信息
- 章节号：9.3.1
- 章节标题：入选标准
- 标题层级：### (三级标题)

## 输出格式
详见 [入选标准]() 章节。

## 输出要求
- 保持专业、客观的语气
- 遵循 CSR 正文风格
```
