# CSR 章节内容类型分类

## 一、六大内容类型

### 1. 定义型

**特征**：从 CSP/SAP 等方案文档中提取原文定义，要求逐字保留或最小必要整合。

**典型章节**：
- 9.1.1 研究结束定义
- 9.1.2 研究终止定义
- 9.3.1 入选标准
- 9.3.2 排除标准
- 9.4.1 给予的治疗
- 9.4.6 盲法
- 9.7.1.2 分析数据集
- 9.7.1.12.2.1 PFS

**判断标准**：
- 例文内容主要是对方案定义的复述
- 语言风格为"本研究……""将……""依据……"
- 不包含具体统计数据或表格数据
- 内容来源明确指向 CSP 或 SAP

**工具配置**：
- 主工具：`read_document`
- 参数重点：`requirement`（检索主题）、`keywords`（关键词列表）
- 来源优先级：定义型内容以 CSP 或 SAP 为准，需在提示词中明确

**写作规则提取重点**：
- 提取原文定义的引用方式（逐字引用、最小整合）
- 提取定义的层级结构（编号、缩进）
- 提取术语使用规范
- 提取定义之间的逻辑关系

---

### 2. 数据摘要型

**特征**：从 TFL 表格中提取汇总数据，按固定模板生成描述性段落。

**典型章节**：
- 10.1 患者处置
- 11.2.1 人口统计学
- 11.2.2 基线疾病特征
- 12.2.1 不良事件概要
- 12.1 药物暴露

**判断标准**：
- 例文包含大量"例数（百分比）"格式的数据
- 段落结构固定：总体情况 → 分组描述 → 小结
- 引用了具体表格（表号、表名）
- 数据来源为 TFL 表格

**工具配置**：
- 主工具：`read_tfl`
- 次要工具：`link_tableslisting`（个体数据引用）、`read_figure`（流程图）
- 参数重点：`folderPath`（表格目录）、`requirement`（检索关键词）

**写作规则提取重点**：
- 提取每段描述什么（主题/目的）
- 提取具体的句式结构（如"共X例（XX.X%）受试者发生..."）
- 提取表格绑定字段（哪些数据从表格中提取）
- 提取通用格式模板（如何处理不同数据）
- 提取数据比较方式（组间比较、趋势描述）

**通用格式模板示例**：
```
[药物A]的[指标]为[数值][单位]（SD：[数值]），略高于/低于[药物B]的[数值][单位]（SD：[数值]）
```

---

### 3. 数据列举型

**特征**：从 TFL 表格中提取详细列表数据，按阈值筛选后逐一列出。

**典型章节**：
- 12.2.2 不良事件的列出
- 12.3.1.1 死亡
- 12.3.1.2 其他严重不良事件
- 12.3.1.3 其他重要不良事件
- 12.4 临床实验室评估

**判断标准**：
- 例文包含大量分类列表（如按 SOC/PT 分类的 AE）
- 使用阈值筛选（如"发生率≥20%的TEAE"）
- 数据呈现为"名称（X% vs X%）"格式
- 引用了详细列表表格

**工具配置**：
- 主工具：`read_tfl`
- 次要工具：`link_tableslisting`
- 参数重点：`folderPath`、`requirement`（分类关键词）

**写作规则提取重点**：
- 提取阈值筛选规则（如何确定筛选条件）
- 提取分类层级描述（SOC→PT的描述方式）
- 提取数据列举格式（"名称（X% vs X%）"的变体）
- 提取分组对比方式

**通用格式模板示例**：
```
[事件名称]：[分组1] [数值]例（[百分比]%），[分组2] [数值]例（[百分比]%）
```

---

### 4. 设计讨论型

**特征**：整合 CSP/SAP 多处信息，形成研究设计的论述性段落。

**典型章节**：
- 8 研究目标
- 9.2 研究设计的讨论
- 9.4.4 研究中的剂量选择
- 9.5.2 评估的合理性

**判断标准**：
- 例文包含多个子节，每个子节讨论不同设计要素
- 内容涉及背景依据、设计 rationale
- 允许跨段整合，但不允许脑补
- 可能包含表格（如研究目的表）

**工具配置**：
- 主工具：`read_document`
- 来源：CSP 为主，SAP 补充
- 参数重点：`requirement`（设计要素）、`keywords`（背景关键词）

**写作规则提取重点**：
- 提取论述结构（背景→依据→结论）
- 提取信息整合方式（多源信息如何串联）
- 提取论证逻辑（因果关系、对比分析）
- 提取术语使用规范

---

### 5. 流程型

**特征**：描述研究执行流程、操作步骤或管理要求。

**典型章节**：
- 9.6 数据质量保证
- 9.8.1 研究实施过程中方案的变更
- 10.2 方案偏离
- 11.3 用药依从性的衡量

**判断标准**：
- 例文按时间或逻辑顺序展开
- 内容涉及操作流程、职责分工、质量控制
- 可能包含流程图引用
- 不包含具体统计数据

**工具配置**：
- 主工具：`read_document`（流程定义）或 `read_tfl`（流程数据）
- 次要工具：`read_figure`（流程图）、`link_tableslisting`
- 根据例文实际引用的数据源确定

**写作规则提取重点**：
- 提取流程描述顺序（时间顺序、逻辑顺序）
- 提取步骤描述格式（动词开头、条件判断）
- 提取角色/职责描述方式
- 提取流程图引用方式

---

### 6. 综合讨论型

**特征**：整合 TFL 表格数据、文献引用、研究设计信息等多源内容，形成综合论述性段落。

**典型章节**：
- 13.1 讨论
- 13.2 局限性
- 14.1 结论

**判断标准**：
- 例文包含多个段落，每段从不同角度讨论（疗效、安全性、亚组、比较研究）
- 同时引用 TFL 表格数据和文献参考
- 需要综合多源信息形成论述
- 段落间有逻辑递进关系

**工具配置**：
- 主工具：`read_tfl`（表格数据）、`read_document`（文献引用）
- 次要工具：`link_tableslisting`（详细数据引用）
- 参数重点：`folderPath`、`requirement`（检索主题）、`keywords`（文献关键词）

**写作规则提取重点**：
- 提取多源信息整合方式（表格数据+文献引用）
- 提取论述逻辑结构（数据→讨论→比较→结论）
- 提取文献引用格式
- 提取对比分析方式（与外部研究比较）

---

### 7. 简单章节型

**特征**：例文非常简短（通常只有一句话），不包含复杂的数据结构或段落组织。

**判断标准**：
- 例文长度：通常只有一句话或几句话
- 例文内容：可能包含"见表格 X.X"、"详见附表"、"见 X.X 章节"等引用
- 数据结构：不包含复杂的段落组织或数据结构
- 输出格式：固定格式输出，如"见表格 X.X"或固定陈述

**内容特点**：
1. 例文通常只包含一句话或几句话
2. 例文可能引用表格、章节或附件
3. 输出格式固定，不需要复杂的段落组织
4. 不包含具体统计数据或详细描述

**工具配置**：
- 主工具：根据例文分析确定
  - 如果例文引用了表格（如"见表 X.X"），使用 `read_tfl`
  - 如果例文引用了章节（如"见 X.X 章节"），不使用工具，直接在提示词中写明章节名称
  - 如果例文没有引用任何内容，可能不需要使用任何工具
- 次要工具：无

**写作规则提取重点**：
- 提取例文引用的内容类型（表格、章节、附件）
- 提取固定输出格式
- 提取检索关键词（从引用内容中提取）

**章节引用处理规则**：
- 如果例文引用了章节（如"见 9.3.1 入选标准"），不使用 `read_document` 工具
- 直接在提示词中写明章节名称，使用 `[章节名称]()` 格式生成可点击链接
- 章节名称从例文中提取，不要使用章节编号

**输出格式示例**：
```
情况一：引用表格
个体疗效数据列表见表 11.4.3-01。

情况二：引用章节
详见 [入选标准]() 章节。

情况三：无引用内容
个体疗效数据列表见相应的统计分析表格。
```

## 二、类型判断流程

```
例文分析
  ↓
例文长度是否非常简短（≤1句话）？
  ├── 是 → 是否包含表格引用（"见表 X.X"）或章节引用（"见 X.X 章节"）？
  │         ├── 是 → 简单章节型
  │         └── 否 → 是否包含固定格式输出？
  │                   ├── 是 → 简单章节型
  │                   └── 否 → 根据内容特征判断其他类型
  └── 否 → 是否包含具体统计数据（例数、百分比、统计量）？
            ├── 是 → 是否为汇总统计（总体+分组）？
            │         ├── 是 → 是否同时引用文献进行比较讨论？
            │         │         ├── 是 → 综合讨论型
            │         │         └── 否 → 数据摘要型
            │         └── 否 → 是否为分类列表（按 SOC/PT 等）？
            │                   ├── 是 → 数据列举型
            │                   └── 否 → 流程型（含统计数据的流程）
            └── 否 → 是否为方案定义复述？
                      ├── 是 → 定义型
                      └── 否 → 是否涉及设计 rationale？
                                ├── 是 → 设计讨论型
                                └── 否 → 是否需要综合多源信息形成论述？
                                          ├── 是 → 综合讨论型
                                          └── 否 → 流程型
```

## 三、混合类型处理

部分章节可能同时包含多种类型的内容。处理方式：

1. **以主要类型为主**：选择占例文比例最大的类型
2. **子节分级处理**：如果子节之间类型不同，可在提示词中为每个子节指定不同的工具配置
3. **工具叠加**：同时配置多种工具，在执行步骤中分别调用

示例 1：9.2 研究设计的讨论
- 9.2.1 受试者选择 → 定义型（read_document）
- 9.2.2 对照组选择 → 设计讨论型（read_document）
- 9.2.3 双盲 → 定义型（read_document）
- 9.2.4 研究终点 → 定义型（read_document）
- 整体类型：设计讨论型（因为需要整合多源信息）

示例 2：13.1 讨论
- 13.1.1 疗效总结 → 数据摘要型（read_tfl）
- 13.1.2 亚组分析 → 数据摘要型（read_tfl）+ 综合讨论型（文献比较）
- 13.1.3 安全性总结 → 数据摘要型（read_tfl）
- 13.1.4 比较研究 → 综合讨论型（read_tfl + 文献引用）
- 整体类型：综合讨论型（需要整合表格数据和文献信息形成论述）

## 四、写作规则提取指南

对于每种内容类型，在分析例文时应重点提取以下写作规则：

### 4.1 段落功能描述
- 每段描述什么（主题/目的）
- 每段在整体章节中的位置和作用

### 4.2 句式结构分析
- 段落的开头、中间、结尾格式
- 数据呈现方式（例数+百分比、统计量、引用格式）
- 固定描述模式（如"共X例（XX.X%）受试者发生..."）

### 4.3 表格绑定内容识别
- 哪些字段是从表格中提取的
- 这些字段在表格中的位置（行定义、列定义）
- 这些字段的格式要求（小数位数、单位、百分比格式）
- 这些字段与其他字段的关系（如分子/分母、试验组/对照组）

### 4.4 通用格式模板提取
- 将表格绑定内容写成通用格式模板
- 使用占位符表示可变数据（如 [药物名称]、[分组名称]、[数值]）
- 确保模板能应对不同的表格数据（如更换研究对象、TFL表格内容变化）

### 4.5 固定字段与变量字段识别
- 识别哪些是模板锁定的固定字段（标题、标签、固定句式）
- 识别哪些是来自项目输入的变量字段（名称、数值、单位）
- 变量字段应写成占位符或输入要求，不固化为默认内容
